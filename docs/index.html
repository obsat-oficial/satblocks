🛰️ Guia de Voo SatBlocks — OBSAT 2026

O SatBlocks by BIPES é a plataforma oficial de programação visual baseada em blocos para a Olimpíada Brasileira de Satélites. Projetado para transformar conceitos de engenharia espacial em algoritmos intuitivos e poderosos para CubeSats, CanSats e Estações Terrenas.

1. Ciclo de Missão do Satélite (Flight Sequence)

Um programa de voo espacial típico segue a arquitetura de subsistemas aeroespaciais:

  • Iniciação e Armamento: Aguarda a liberação pelo foguete lançador ou balão estratosférico e emite o pulso de rádio beacon.
  • Coleta de Telemetria: Lê os sensores ambientais (pressão barométrica BMP280, temperatura, luminosidade solar e umidade).
  • Controle de Atitude & Detecção de Queda: O acelerômetro/giroscópio MPU6050 monitora o apogeu e detecta o momento exato de queda livre (microgravidade).
  • Transmissão de Pacotes LoRa: Envia os dados científicos formatados em CSV para a estação de solo a cada 1 segundo.
  • Ejeção do Paraquedas: Ao atingir a altitude de acionamento seguro, o servomotor libera o paraquedas para pouso suave.

2. Exemplo de Programa de Voo Completo em MicroPython

O código equivalente gerado automaticamente pelo SatBlocks:

from machine import Pin, I2C, PWM, ADC
import time, math, bmp280, mpu6050

# 1. Inicializacao dos Sensores
i2c = I2C(0, scl=Pin(22), sda=Pin(21))
bmp = bmp280.BMP280(i2c)
imu = mpu6050.accel(i2c)
servo = PWM(Pin(18), freq=50)

print("[OBSAT] Missao CANSAT_01 iniciada com sucesso!")

# 2. Laco de Telemetria de Voo
for ciclo in range(100):
    temp = bmp.temperature
    press = bmp.pressure / 100.0
    alt = 44330.0 * (1.0 - math.pow(press / 1013.25, 0.1903))
    
    # Formata pacote CSV
    pacote = f"SAT01,{ciclo},{temp:.2f},{press:.2f},{alt:.2f}"
    print("[LORA TX] ->", pacote)
    
    # Detecção de Apogeu e Abertura de Paraquedas
    if alt < 300.0 and ciclo > 10:
        servo.duty(75) # 90 graus para liberacao
        print("[PAYLOAD] Paraquedas acionado!")
        
    time.sleep(1)

3. Criando Novos Blocos no SatBlocks Studio

Se a sua equipe construiu uma carga útil científica com um sensor inédito (ex: sensor de CO₂, radiação Gama ou espectrofotômetro), utilize o SatBlocks Studio:

  1. Abra o SatBlocks Studio no topo da página.
  2. Desenhe a geometria do bloco (campos de texto, dropdowns de portas GPIO, saídas numéricas).
  3. Escreva o código MicroPython correspondente no painel de gerador.
  4. Exporte a imagem em PNG HD (300 DPI) ou SVG para anexar diretamente no relatório de missão ou simulado da OBSAT!
